# Arize18.co.za

Arize18 is a travel and tours company website.  
It showcases the services offered to clients, including car bookings and the types of vehicles available in the company fleet.

## 🌍 Client Services

Clients can book a variety of services:

1. Airport Transfers  
2. Hotel Transfers  
3. Tours and Safaris  
4. Chauffeur Drive  
5. Self-Driven Hire  
6. Door-to-Door  
7. Social Events  

## 🛠 Admin Site

The admin section is built using the **Filament plugin**.  
It allows authorized users to:

- Update contact details, Services and the About Us page  
- Add or edit cars in the fleet  
- Generate and print invoices/quotations  
- Create new quotes linked to client bookings  

## 📦 Tech Stack

- **Frontend:** Website showcasing services and cars  
- **Backend:** Laravel with Filament for admin management  
- **Database:** MySQL (for bookings, cars, and quotations)  

## 🚀 Features

- Simple booking flow for multiple travel services  
- Automatically emails the admin when a client submits a booking  
- Admin dashboard for managing content and bookings  
- Quotation generation with printable invoices
